# 🌦️ Weather Dashboard

## Project Overview
The Weather Dashboard is a web application that displays current weather information for a city entered by the user. It uses public REST APIs to retrieve weather data.

## Features
- Search weather by city name
- Display temperature in Celsius
- Display humidity percentage
- Display wind speed in km/h
- Show current weather conditions
- Display feels-like temperature
- Handle invalid city names and API errors
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- REST API
- JSON

## APIs Used
- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

Website: https://open-meteo.com/

No API key is required.

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Weather API integration and application logic
- `README.md` – Project documentation

## How to Run
1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Run `index.html` using Live Server.
4. Enter a city name such as Pune or Mumbai.
5. Click Search to view the weather.

An active internet connection is required.
